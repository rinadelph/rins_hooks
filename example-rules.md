# Project Hook Rules

## Code Quality
- Format JavaScript files after editing
- Run ESLint after modifying JavaScript files
- Check for TypeScript errors before saving

## Testing
- Run npm test before committing
- Validate test coverage after running tests

## Security  
- Scan for hardcoded secrets before saving files
- Check for vulnerable dependencies when modifying package.json

## Build Process
- Build project when modifying source files
- Update documentation after editing README files
